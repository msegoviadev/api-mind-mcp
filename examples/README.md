# Example API Specs

This directory contains example `.mind` files to help you get started.

## What are .mind files?

`.mind` files are token-optimized representations of OpenAPI/Swagger specs, generated by [spec-mind](https://github.com/msegoviadev/spec-mind).

## Generating Your Own .mind Files

1. Install spec-mind:
   ```bash
   npm install -g @msegoviadev/spec-mind
   ```

2. Place your OpenAPI/Swagger specs in a `specs/` directory:
   ```bash
   mkdir specs
   # Copy your api1.yaml, api2.json files to specs/
   ```

3. Generate `.mind` files:
   ```bash
   spec-mind sync --no-notation ./specs/
   ```

4. Commit both files:
   ```bash
   git add specs/*.yaml specs/*.mind
   git commit -m "Add API specs"
   ```

## Example: jsonplaceholder.mind

The included `jsonplaceholder.mind` is generated from the JSONPlaceholder API (https://jsonplaceholder.typicode.com/), a free fake REST API for testing and prototyping.

You can use it to test api-mind-mcp:
```bash
claude mcp add --transport stdio api-mind \
  -- npx -y @msegoviadev/api-mind-mcp /path/to/api-mind-claude/examples
```

## Why --no-notation?

The `--no-notation` flag strips the NOTATION legend from individual `.mind` files because api-mind-mcp includes it once in the tool description. This saves tokens when loading multiple APIs.

If you need the NOTATION for manual inspection, omit the flag:
```bash
spec-mind sync ./specs/  # Includes NOTATION in each file
```
